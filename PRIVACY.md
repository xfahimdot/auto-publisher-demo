# Privacy Policy for auto-publisher

**Last updated: October 19, 2026**

## Overview

auto-publisher is a personal tool that uploads videos to the owner's own YouTube channel using the YouTube Data API v3. It is used only by its owner.

## Data We Access

The app requests permission to upload videos to the YouTube channel of the Google account that authorizes it (scope: `youtube.upload`). It does not read, collect, or store any personal information from other users.

## How Data Is Used
- The authorization (refresh token) is stored privately by the owner and is used only to upload the owner's videos.
- No data is sold, shared, or disclosed to any third party.
- No analytics, advertising, or tracking is used.

## YouTube API Services

This app uses YouTube API Services. By using it, the owner agrees to be bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms) and the [Google Privacy Policy](https://policies.google.com/privacy).

## Revoking Access

Access can be revoked at any time at https://myaccount.google.com/permissions.
